---
description: Lancer les vérifications (types, lint, tests) et résumer
---
1. Lance `npx next typegen`, `npm run typecheck`, `npm run lint`, puis `npm test` (ou `npm run test:watch` si l'argument est `watch` : ne bloque pas le terminal, indique-moi comment l'arrêter).
2. Si échec : analyse la **cause** (pas le symptôme), corrige le code ou le test fautif. Interdit : supprimer/assouplir un test pour passer.
3. Résume : commandes lancées, résultat (nombre de tests), critères de la fiche couverts/manquants.
