# Plans

Un fichier par plan validé : `AAAA-MM-JJ-<slug>.md`, produit par `/plan`.
Contenu : objectif · fiche liée · contrat (Zod/GraphQL) · tâches par couche (database → backend → frontend → qa) · fichiers touchés · tests · risques · décisions à prendre · **statut : brouillon | approuvé | terminé**.
`/build` refuse de démarrer si le statut n'est pas « approuvé ».
