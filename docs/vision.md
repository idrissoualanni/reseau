# Vision

**Ton profil se construit sur ce que tu apprends vraiment, pas sur ce que tu déclares.**

Un réseau social où ce que l'on apprend et construit devient son profil, son CV et sa visibilité professionnelle. Modulable (plusieurs types de profils), premier public : les étudiants, avec une communauté ouverte de personnes curieuses (autodidactes, reconversion, entrepreneurs) ensuite.

| Réseau classique | Ce projet |
|---|---|
| Profil déclaré | Profil construit sur des **preuves** (projets publiés, artefacts) |
| CV rédigé à la main | CV **généré puis modifiable** à partir de l'activité |
| Un seul fil pour tous | **Espaces** (université, filière, thème) à visibilité maîtrisée |
| Pensé pour profils établis | Pensé pour ceux qui **apprennent et débutent** |

## Problèmes adressés
1. Les étudiants ne savent pas valoriser ce qu'ils savent faire (le CV reflète le diplôme, pas les compétences).
2. Les profils hybrides sont invisibles pour les outils de recrutement.
3. Le réseautage est difficile sans contacts familiaux ou professionnels.
4. Les entrepreneurs débutants manquent de ressources (mentors, financements, partenaires).
5. Les universités manquent d'outils pour suivre l'insertion de leurs étudiants.

## Principes produit
- **Preuve avant déclaration** : une compétence est plus crédible quand elle est liée à un projet.
- **L'utilisateur garde la main** : il décide ce qui alimente son profil professionnel ; l'IA propose, il valide (V1.5+).
- **Valeur utile même en solo** : profil, projets et CV servent avant que le réseau soit rempli.
- **Une chose à la fois** : un module livré et validé avant le suivant.
