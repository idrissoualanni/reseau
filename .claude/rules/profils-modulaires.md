- Le cœur (utilisateur, publication, relation, messagerie) ne connaît aucun type de profil.
- Un type de profil (étudiant, entrepreneur…) est un module : ses champs, sa logique de déduction
  de compétences et son modèle de CV vivent dans son propre dossier.
- Ajouter un type de profil ne doit pas modifier le cœur (skill `nouveau-type-de-profil`).
- Les universités s'intègrent par configuration, pas par code spécifique.
