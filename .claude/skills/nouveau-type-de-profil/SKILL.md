---
name: nouveau-type-de-profil
description: Ajouter un nouveau type de profil (ex. entrepreneur) sans toucher au cœur du réseau.
---

1. Crée un dossier de module pour le type de profil.
2. Définis ses champs spécifiques, sa déduction de compétences, son modèle de CV.
3. Branche le module via le mécanisme d'enregistrement des profils (ne modifie pas le cœur).
4. Ajoute les tests du module et une entrée dans docs/architecture.md.
5. Si le cœur doit changer, arrête-toi et demande-moi d'abord.
